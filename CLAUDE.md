# Tetris 2.0

Swift Playgrounds app project (.swiftpm), built and run only on iPad. No Xcode, no Mac, no simulator.

- Swift 6, SwiftUI, iOS 26 target
- Don't edit Package.swift by hand; Playgrounds regenerates it
- You can't build or run this code, so keep changes small and explain how to test them on device
- No .metal files; Metal shaders go in Swift strings compiled at runtime
- Controls: keyboard (W/A/S/D/H) and game controller

Goals: portfolio piece, not for the App Store. Daily seeded challenge, pure deterministic engine, bitboards, Metal renderer.
