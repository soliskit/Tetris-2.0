# Tetris 2.0

A modern take on Tetris built entirely on an iPad with Swift Playgrounds. It uses SwiftUI and plays with touch, a hardware keyboard, or a game controller.

This is a portfolio project and is not intended for the App Store.

## Features

* **7 bag randomizer** so every piece appears once in each group of seven
* **SRS wall kicks** for all pieces, including the separate I piece kick table
* **Ghost piece** showing where the current piece will land
* **Hold** with one swap per piece
* **Three piece preview** of upcoming pieces
* **Lock delay** of 0.5 seconds, reset by moving or rotating up to 15 times per row
* **Autosave** on pause and after every line clear, with a Continue option on the start screen
* **High score** kept between launches

## Controls

### Touch

| Action | Gesture |
| --- | --- |
| Move | Drag left or right on the board |
| Soft drop | Drag down on the board |
| Rotate | Tap the board |
| Hold | Tap the hold box (top left) |
| Pause / resume | Tap the pause button |

### Keyboard

| Key | Action |
| --- | --- |
| A / D | Move left / right (hold to repeat) |
| W | Rotate |
| S | Hard drop |
| H | Hold |
| P or Esc | Pause / resume |
| Return | New game |
| C | Continue saved game |

### Game controller

| Input | Action |
| --- | --- |
| Left stick left / right | Move (hold to repeat) |
| Left stick down | Soft drop |
| B | Rotate |
| A | Hard drop |
| X | Hold |
| Menu | New game, or pause / resume |
| Y | Continue saved game |

Held movement uses a 167 ms delay before repeating, then repeats every 33 ms.

## Scoring

| Lines cleared | Points |
| --- | --- |
| 1 | 100 |
| 2 | 300 |
| 3 | 500 |
| 4 | 800 |

The level goes up every 1,000 points. Pieces fall every 0.7 seconds at level 1, 0.02 seconds faster each level, and never faster than 0.25 seconds.

## Running the project

You need an iPad with Swift Playgrounds installed.

1. Clone the repository into a folder whose name ends in `.swiftpm`, for example `Tetris 2.0.swiftpm`. An iPad Git client such as Working Copy can clone straight into the Files app.
2. Open that folder in Swift Playgrounds.
3. Tap Run.

`Package.swift` is generated by Swift Playgrounds, so change app settings from inside the app instead of editing that file.

## Project structure

```
MyApp.swift                 App entry point
ContentView.swift           Main screen layout and touch gestures
GameManager.swift           Game loop, rules, scoring, save and load
Model/                      Tetromino, board cell, position, game state and saved session types
View/                       Board, piece preview and button views
Support/                    Piece factory, controller and keyboard input, helpers
```
